# JavaScript Authentication & User Management 

A responsive authentication and user management system built with HTML, CSS, and JavaScript, featuring user registration, login, profile management, a personal To-Do List, and an admin panel.

##  Features

* User registration
* User login
* User profile
* Personal To-Do List
* Admin panel
* Edit users
* Delete users
* User and admin access control
* Responsive design

##  Technologies

* HTML5
* CSS3
* JavaScript
* JSON Server
* npm


##  Getting Started

### Install dependencies

npm install

### Run JSON Server

npx json-server --watch db.json

### Run the project

Open `index.html` in your browser.
